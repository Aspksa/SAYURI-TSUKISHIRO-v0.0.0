# SAYURI TSUKISHIRO · 月白 · v0.0.0

Локальная портативная система для Windows: ядро, заметки в SQLite, личный **Диск** с файлами и обновление прямо из этого репозитория. Без облака, без регистрации, данные лежат рядом с программой: на HDD, SSD или флешке.

## Возможности

| Раздел | Что делает |
| --- | --- |
| **Обзор** | Состояние ядра, число заметок, версия |
| **Диск** | Папки, загрузка файлов (кнопкой и перетаскиванием), скачивание, превью картинок, переименование, корзина с восстановлением, индикатор свободного места |
| **База данных** | Заметки в SQLite (`data/sayuri.db`), переживают перезапуск |
| **Обновление** | Проверка и загрузка новых файлов приложения из ветки `main` |

## Быстрый старт

Нужен Python 3 для Windows (подойдёт и портативный в `runtime/python/python.exe`).

```bat
git clone https://github.com/Aspksa/SAYURI-TSUKISHIRO-v0.0.0.git
cd SAYURI-TSUKISHIRO-v0.0.0
SAYURITSUKISHIRO.bat
```

Лаунчер применит подготовленные обновления, запустит сервер и откроет `http://127.0.0.1:8765`. Остановить: `Ctrl+C` в окне BAT.

## Диск

Файлы хранятся в `data/disk/files`, удалённые лежат в `data/disk/trash` до очистки корзины.

- Одинаковые имена не перезаписываются: `photo.jpg` → `photo (1).jpg`.
- Лимит одного файла: 4 ГБ. Загрузка идёт во временный файл, оборванная не оставляет мусора.
- Путь жёстко ограничен папкой диска (`..`, абсолютные пути и зарезервированные имена Windows отклоняются).
- Скачивание безопасное: кроме картинок, все файлы отдаются только как вложение и не выполняются в браузере.

## Обновление из GitHub

Раздел **Обновление** отслеживает ветку `main` этого репозитория.

1. Нажмите «Проверить обновления», затем «Подготовить обновление».
2. Остановите BAT (`Ctrl+C`) и запустите `SAYURITSUKISHIRO.bat` снова. Файлы применятся до старта сервера.
3. При ошибке выполняется откат, копия прежних файлов лежит в `data/.updates/backup`.

Файлы сверяются по SHA-1 блобов GitHub и ограничены списком из `update-manifest.json`. База, `data/` и `runtime/` не затрагиваются. Подробнее: [PORTABLE.md](PORTABLE.md).

## Структура

```
SAYURITSUKISHIRO.bat   лаунчер
update-manifest.json   список файлов, которые может обновлять апдейтер
sayuri/                серверная часть (core, storage, disk, updater, web)
web/index.html         интерфейс (один файл, без внешних зависимостей)
tests/                 unit-тесты
data/                  ваши данные (не в git, не обновляются)
```

## Безопасность

- Сервер слушает только `127.0.0.1`, без авторизации. **Не выставляйте его в локальную сеть или интернет.**
- Защита от DNS-rebinding и кросс-сайтовых запросов (проверка `Host`, `Origin` и `Content-Type`).
- Обновления исполняются при следующем запуске, поэтому доверяйте только изменениям в `main`.
- Не вынимайте флешку, пока Sayuri запущена.
